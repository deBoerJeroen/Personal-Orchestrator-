# Not now

Functies die we bewust niet bouwen. Toevoegen aan deze lijst mag altijd.
**Verwijderen uit deze lijst vereist dat je opschrijft welk uitvoeringsprobleem
het oplost** — niet welk overzichtsprobleem.

Vastgesteld op 2026-07-28, bij de start van fase 1.

| Functie | Reden |
|---|---|
| Dashboards en grafieken | Je gaat de app dan lezen in plaats van gebruiken |
| Complexe statistieken | Nieuw speelgoed voor motion |
| Sociale features, publieke profielen | Eén gebruiker; delen lost niets op |
| Gamification: punten, levels, badges | Veroorzaakt kunstmatig gedrag en schuld |
| Streaks prominent tonen | Eén gemiste dag mag niet voelen als verlies |
| AI-chat als hoofdscherm in de app | Coaching hoort te eindigen in gedrag, niet in gesprek |
| Volwaardige agenda | Er is al een agenda; deze app is er niet nog een |
| Notitie-app, documentbeheer | Scope van een tweede product |
| Teamfunctionaliteit | Niet van toepassing |
| Tags | De vaakst gebruikte manier om een takenlijst in een archief te veranderen |
| Subtaken dieper dan één niveau | Oneindig kleiner maken is ook uitstel |
| Automatiseringen, regels-editor | Onderhoud dat de app niet mag kosten |
| Meerdere prioriteringsmethodes (Eisenhower, MoSCoW, ABC) | Kiezen tussen methodes is motion |
| Lange onboarding | Het systeem hoeft niet eerst ingericht |
| Thema's en personalisatie | Instellingen beheren is geen uitvoering |
| Avatars voor agents | Kost aandacht, levert niets |
| Moodtracking met grafieken | Meten zonder handelen |
| Financiële tracking, gezondheidsintegraties | Ander probleem |
| Slack / Gmail / Notion-integraties | Pas als de kern echt werkt |
| Offline-first sync met conflictresolutie | Zware machinerie voor één gebruiker met één apparaat tegelijk |
| Multi-user | Niet nodig; `user_id` staat wel overal klaar |
| Native mobiele app | PWA is genoeg zodra push werkt |

## Uitgesteld, niet geschrapt

Deze horen bij een latere fase en hebben een concreet startsein:

| Functie | Fase | Startsein |
|---|---|---|
| Gewoontes, minimale versie, herstel na missen | 2 | Fase 1 vijf dagen echt gebruikt |
| Let Them-flow, weekly review, motion-patronen | 3 | Fase 2 twee weken gelopen |
| Claude Code coach-CLI en skills | 3 | Samen met fase 3 |
| Pushnotificaties (VAPID), quiet hours | 4 | Fase 3 af en app op beginscherm geïnstalleerd |
| Agenda lezen via ICS, spraakcapture | 4 | Alleen als tekstcapture aantoonbaar te traag is |
| In-app AI-clarify (Anthropic API) | 5 | Alleen als de coachlaag op de laptop structureel knelt |
| App-level encryptie van check-in-tekst | 5 | Als de app echt als dagboek gebruikt wordt |
